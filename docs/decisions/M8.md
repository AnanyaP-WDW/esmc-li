# M8 — package and CLI

**Result.** `ProteinIndex` (`from_fasta/build/load/search/search_batch`) and
`esmc-retrieval build/search/benchmark` ship. Query rows use esmc.cpp
`--keep-special` (commit `28a3913`) + the packaged 960->128 head; index rows
retain BOS/EOS to match the frozen scorer. Search is exact numpy MaxSim; no
torch dependency. The index sidecar records head/model hashes and the head is
copied to `<index>.head.npy`. Wheel contains the head and target-install
search works. Tests: 40 pass; 1K SCOPe smoke is 10/10 top-1 same superfamily
(8/10 same family; 23.2 s build+search, 50 MB index); long >2046 chunking
covered.

**Decision.** Ship the package/CLI as v0. Query encoding stays CLI-based
(model load per single query; `search_batch` uses one process); add a shared
library bridge only if measured query latency requires it. Index build uses
`--keep-special`, not the old stripping path. Q4 GGUFs warn. Indexes remain a
separate optional artifact; the index is not self-contained without its
head/model.
